# 🎓 Student Performance Analytics System

### 🚀 EWB Python with AI Internship Project

A Python-based data analytics project developed as part of the **EWB Python with AI Internship**, focused on analyzing student academic performance using Python, Pandas, and NumPy.

---

## 📌 About the Project

The **Student Performance Analytics System** analyzes student marks and attendance data to generate meaningful academic insights.

This project demonstrates the practical application of Python programming fundamentals and data analysis techniques to transform raw student records into useful performance summaries.

🎯 **Project Goal:** Understand student performance through marks analysis, grading, pass/fail classification, subject-wise comparison, and attendance-performance analysis.

## 🎯 Project Objectives

* 📂 Load and explore student data using Pandas.
* 🧮 Calculate total and average marks for each student.
* 🏅 Assign grades based on average marks.
* ✅ Identify Pass/Fail status.
* 📈 Calculate the overall class average.
* 🔍 Identify the highest- and lowest-performing students.
* 📚 Analyze subject-wise average marks.
* 🏆 Identify the top 5 performing students.
* 📊 Calculate Pass/Fail counts and percentages.
* 🔗 Analyze the correlation between attendance and average marks.
* 📝 Generate a final student performance summary.

## 📂 Dataset Description

The project uses a CSV dataset containing **300 student records** with eight columns.

| Column          | Description               |

| `Python`        | Python marks              |
| `SQL`           | SQL marks                 |
| `Mathematics`   | Mathematics marks         |
| `Data_Analysis` | Data Analysis marks       |
| `Attendance`    | Attendance percentage     |

📌 The dataset supports student-level calculations and subject-wise performance analysis.

## 📏 Grade Assignment Criteria

| Average Marks | Grade |
| ------------- | ----- |
| 90–100        | A+    |
| 80–89         | A     |
| 70–79         | B     |
| 60–69         | C     |
| 50–59         | D     |
| Below 50      | F     |

### ✅ Pass/Fail Rule

A student is classified as **Pass** if they score at least 40 marks in every subject. If they score below 40 in any subject, their result is classified as **Fail**.

## ⚙️ How to Run the Project

**Step 1:** Clone or download this repository.

**Step 2:** Open `Student_Performance_Analytics.ipynb` in Google Colab.

**Step 3:** Upload `students.csv` to the Colab environment.

**Step 4:** Verify that the notebook uses the correct dataset file path.

**Step 5:** Run the notebook cells in order to generate the analysis results.
